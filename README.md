# Xeno

**Xeno** — экспериментальный компилируемый язык программирования с собственным лексером, парсером, абстрактным синтаксическим деревом, проверкой типов и генерацией кода на языке Си.

Проект написан на Си и использует GCC для компиляции программ.

## Возможности

- Собственный синтаксис языка.
- Лексический анализ исходного кода.
- Парсер и абстрактное синтаксическое дерево (AST).
- Проверка типов.
- Генерация исходного кода на Си.
- Компиляция с помощью GCC.
- Статическая типизация и явное объявление типов.

## Пример программы

```xeno
fn main() -> i32 {
    let x: i32 = 6 * 7;
    ConsoleOut.write(`6 * 7 is ${x}`);
    return 0;
}
```

Ожидаемый вывод:

```text
6 * 7 is 42
```

> Примечание: пример демонстрирует предполагаемый синтаксис языка. Поддержка отдельных возможностей, включая шаблонные строки, зависит от текущей реализации компилятора. А это не реализовано.

## Сборка

Для сборки проекта необходимы:

- GCC;
- Make;
- среда MinGW-w64 или другая совместимая среда с компилятором Си.

Если в репозитории присутствует `Makefile`, соберите проект командой:

```bash
make
```

После успешной сборки запустите полученный исполняемый файл.
